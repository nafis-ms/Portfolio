Apply Changes

Sends the ticked items to your GitHub repository. Vercel then redeploys, and your site updates within about a minute.

What to publish

GitHub settings

On GitHub: Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token. Choose only this repository and set Contents to Read and write. The token is saved in this browser only, so keep this browser private, and delete the token on GitHub if you ever lose control of this computer.
